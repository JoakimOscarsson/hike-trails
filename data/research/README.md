# Research Data

This subtree is for data that is useful to future integrations but is not currently consumed by the app.

Current candidate trails:

| Trail | Path | Current state |
| --- | --- | --- |
| Stockholm Archipelago Trail | `candidate-trails/stockholm-archipelago-trail/` | Trail-level research packet only; not sectionized; not app-ready. |
| Upplandsleden | `candidate-trails/upplandsleden/` | Trail summary, per-section/per-loop packets, and a dedupe registry; needs normalization and import work. |
| Vikingaleden | `candidate-trails/vikingaleden/` | Per-section packets only; overlaps Upplandsleden in places and needs dedupe/integration work. |

Naming note: if a task mentions "Uppsalaleden", the files currently present in this project are for `upplandsleden`.
